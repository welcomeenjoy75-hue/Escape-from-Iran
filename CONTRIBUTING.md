# Contributing Guidelines / 贡献者指南

Welcome to **The Escape Trilogy: Part I — Escape from Iran: The Blind Spot** open-source literary project. This document serves as the constitution for our collaborative writing framework. 

欢迎来到**《逃亡三部曲》第一部 —— 《逃出伊朗：盲区》**开源文学项目。本指南是CONTRIBUTING.md个协作创作的核心守则。

---

## English Version (英文部分)

### 1. General Principles
This project is an open-source, non-commercial realism novel framework. Our primary goal is to create a literary monument for ordinary people using rigorous, zero-bug logic and raw human-sensory details. 

* **Logic First**: Every scene, plot twist, and character decision must follow a strict causal inevitability. We do not tolerate sudden conveniences, character script immunity, or plot holes.
* **Zero AI-Generated Text**: To maintain deep, genuine empathy and grit, all submissions must be entirely written by humans. AI-generated text or descriptions will be systematically rejected.
* **The Blueprint remains Immutable**: The 22-chapter overarching narrative architecture and ultimate character fates are locked. Your contributions should enrich these chapters with structural depth and realistic flesh, rather than derailing the existing storyline.

### 2. What We Need Most
* **Local Iranian Authenticity**: Gritty details of Shiraz and the southern border—including the price of common goods (in Rials/Tomans), architectural textures of the Grand Bazaar, local customs, and everyday Persian expressions.
* **Professional Technical Input**: Authentic representations of auto-mechanic diagnosis (Amir), street-level haggling dynamics (Hassan), and regional geographical patterns or pedagogical setups (Zahra).
* **Sensory and Psychological Depth**: Raw descriptions of hunger, dehydration, sensory overload during checkpoint checks, and internal moral dilemmas.
* **Localization & Translation**: Translating the master framework or individual finalized chapters into high-quality English, Persian, or other languages.

### 3. Workflow (How to Contribute)
We manage this literary project exactly like a mission-critical software engineering repository:

1.  **Fork the Repository**: Create your personal copy of this repository on GitHub.
2.  **Claim or Modify an Issue/Chapter**: Look for existing open issues, or choose a specific chapter within the `chapters/` directory to write, polish, or append realistic details.
3.  **Create a New Branch**: Keep your modifications isolated (e.g., `git checkout -b feature/chapter-06-engine-details`).
4.  **Submit a Pull Request (PR)**: Push your branch to GitHub and open a Pull Request back to our `main` branch. 
5.  **Review Process**: The project maintainers (Showrunners) will review the submission strictly on linguistic grit, emotional consistency, and logical inevitability. Once verified, your text will be merged into the canonical manuscript, and your GitHub ID will be permanently engraved in the contributor list.

## 中文部分 (Chinese Version)

### 1. 核心创作原则
本项目是一项开源、非商业的现实主义长篇小说共创计划。我们的最高宗旨是用最严丝合缝的闭环逻辑与最粗粝的人类视听细节，为底层普通人立一座文字纪念碑。

* **逻辑至上**：每一个场景、情节反转和人物决策都必须遵循绝对的因果必然性。严禁降智情节、降智反派、机械降神（突然出现奇迹）或任何主角光环。
* **绝对禁止AI灌水**：为了保证文字具备真正的悲悯、粗糙感与血肉，所有提交的贡献必须由人类纯手工撰写。任何由大模型批量生成的段落、环境描写或流水账将被一律拒绝。
* **大纲主线锁死**：22章的整体复调架构及三位主角的最终命运走向已经过严格推演并完全锁定。所有的共创应聚焦于在大纲框架内填充、打磨具有张力的细节血肉，而不是破坏既定的主线走向。

### 2. 我们急需哪些细节支持？
* **伊朗本土烟火气**：设拉子老城区、南部边境的写实细节——例如当地物价（里亚尔/土曼）、巴扎（集市）的建筑质感、本土平民的真实风俗、波斯语的市井日常俚语等。
* **跨行业硬核技术**：如南郊黑车间盲修汽车发动机的技术触觉（阿米尔）、大巴扎流动小贩的市井话术与周旋心理（哈桑）、古波斯地理/历史知识在荒原中的实际运用（扎赫拉）。
* **生理与心理高压刻画**：极致饥饿、极度脱水状态下普通人的幻听与体能极限，以及面对零容错体制核查时，普通人骨子里的恐惧与本能爆发出的闪光点。
* **多语言翻译**：将主框架大纲或未来成稿的中文章节翻译、润色为高质量的英文、波斯语，打造真正的跨语圈作品。

### 3. 共创工作流 (如何提交贡献)
我们像管理一个精密的代码项目一样管理这部小说：

1.  **Fork 仓库**：将本项目仓库克隆（Fork）到你个人的 GitHub 账号下。
2.  **认领或修改章节**：查看现有的 Issues 任务列表，或者直接进入 `chapters/` 目录，选择你想撰写、润色或增添细节的特定章节。
3.  **新建分支**：在本地建立独立分支（例如：`git checkout -b feature/chapter-06-engine-details`）。
4.  **提交 Pull Request (PR)**：将修改后的代码/文字推送到你的 GitHub 仓库，并向我们主仓库的 `main` 分支发起 PR。
5.  **主创审核**：主创（架构师）将严格根据“细节粗糙度”、“情感一致性”以及“逻辑必然性”对你的文字进行代码式评审（Code Review）。一旦审核无误，你的文字将被合并（Merge）进正文正片，你的 GitHub 账号也将永久镌刻在项目的贡献者致谢名单中。

## ⚖️ Code of Conduct / 行为准则

* **Intellectual Property (知识产权)**: By submitting a Pull Request, you agree to license your contributed literary content under the project's open-source license, ensuring it remains an open monument for all humanity. (一旦提交 PR 并被合并，即视为您同意将所创内容归入本项目开源许可协议，使其成为属于全人类的公有文字纪念碑)。
* **Mutual Respect (互相尊重)**: We welcome deep logical questioning and rigorous line-by-line critiques in the discussion board, but strictly forbid pure political trolling or malicious personal attacks. (我们极度欢迎在讨论区对大纲进行极其挑剔的逻辑质询与逐字死磕，但坚决杜绝任何无意义的政治引战与恶意人身攻击)。

**Let us weaponize human precision against systemic mundanity. Build the monument.** **让我们用人类特有的精密与悲悯，去对抗规训的洪流。筑巢，立碑。**
